### Suggested LinkedIn post formats (with screenshots)

**Post structure**

1. Hook sentence
2. Side-by-side screenshots
3. Explanation of difference
4. Call-to-action

→ Shows breast cancer approvals, level 3B preclinical hint (RLY-2608), no variant-specific data in cholangiocarcinoma, no suggested next steps.

[Right screenshot: Your tool – Gap Analysis + Suggested Studies]

### Visual tips for screenshots

- Use 2–3 images in carousel
- Crop tightly to the interesting parts
- Add red arrows / highlights if needed (e.g. circle "Minimal evidence" and "High priority", or the study list)
- Include the disclaimer text in at least one image (e.g. "Not for clinical use")

### Which format to start with?

- **Most effective**: Format 1 (side-by-side comparison) — it visually proves the differentiation
- **Most engaging**: Format 3 (poll) — encourages comments and interaction
- **Safest / professional**: Format 2 (before/after) — very clean and academic

Pick one, post it with 2–3 screenshots, and see what kind of responses you get.
